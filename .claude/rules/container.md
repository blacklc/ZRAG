# 容器操作规范
若项目中涉及到容器相关操作, 则应该遵循本文章中的规范.

## 容器镜像构建
- 使用```多阶段构建```的方式来减小镜像的大小.
- 使用```--no-cache```参数来加快镜像构建速度.

## 清理构建环境
- 在清理镜像时, 应保留用作基础镜像的相关镜像.

## 容器资源限制
- 在编写docker compose或启动容器时, 建议与用户进行商讨后再设计具体的容器资源限制.

## 镜像tag
- 在为最新版本的镜像添加版本号tag的同时,也需要为其添加```latest```的tag.
- Git Tag 必须与版本号一一对应：git tag -a v1.2.0 -m "Release v1.2.0"
- 使用 Signed Tag（git tag -s）确保发布来源可信

## 删除容器
- ```不允许擅自删除正在运行的容器.````
